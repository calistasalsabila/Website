# Bootstrap Learning Notes

This document serves as a personal learning note for understanding and using **Bootstrap**, a popular front-end framework for developing responsive and mobile-first websites.

For complete documentation and official guides, refer to the main website:

👉 [Bootstrap Official Documentation](https://getbootstrap.com/)

---

## Overview

Bootstrap provides a collection of CSS and JavaScript tools that help in creating modern, responsive layouts quickly. It includes components like navigation bars, modals, buttons, forms, grids, and more.

### Key Features

* Responsive grid system
* Prebuilt UI components
* Utility classes for spacing, typography, and colors
* Customizable through Sass variables
* JavaScript plugins for interactivity

---

## Learning Path

1. **Understand the Grid System** – Learn how rows and columns define the layout structure.
2. **Explore Components** – Study buttons, cards, modals, and forms.
3. **Work with Utilities** – Learn to use spacing, colors, typography, and display utilities.
4. **Customization** – Modify themes using variables or build custom styles with Sass.
5. **Practice** – Create a few simple responsive layouts using the framework.
