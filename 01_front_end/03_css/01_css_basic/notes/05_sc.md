# Useful VS Code Shortcuts for CSS Editing

This document lists essential shortcuts in Visual Studio Code that are particularly useful when writing and editing CSS. These shortcuts help you work faster by reducing repetitive typing and making code formatting easier.

---

## 1. Join Lines

**Command:** `Join Lines`

* **Windows/Linux:** `Ctrl + Shift + P`, then type `Join Lines`
* **Mac:** `Cmd + Shift + P`, then type `Join Lines`

**Use Case:** Combine multiple CSS declarations into a single shorthand line.

```css
/* Before */
border-style: dashed;
border-top-style: groove;
border-right-style: double;
border-bottom-style: ridge;
border-left-style: inset;

/* After */
border-style: groove double ridge inset;
```

---

## 2. Multi-Cursor Editing

**Command:** Add cursors to multiple lines.

* **Windows/Linux:** `Alt + Click` or `Ctrl + Alt + Down/Up`
* **Mac:** `Option + Click` or `Cmd + Option + Down/Up`

**Use Case:** Edit several CSS properties at once across multiple lines.

---

## 3. Duplicate Line

**Command:** `Duplicate Selection/Line`

* **Windows/Linux:** `Shift + Alt + Down/Up`
* **Mac:** `Shift + Option + Down/Up`

**Use Case:** Quickly duplicate CSS rules or properties without copy-paste.

---

## 4. Move Line

**Command:** `Move Line Up/Down`

* **Windows/Linux:** `Alt + Up/Down`
* **Mac:** `Option + Up/Down`

**Use Case:** Reorder CSS properties or selectors easily.

---

## 5. Format Document

**Command:** `Format Document`

* **Windows/Linux:** `Shift + Alt + F`
* **Mac:** `Shift + Option + F`

**Use Case:** Automatically format CSS with consistent indentation and spacing.

---

## 6. Quick Comment/Uncomment

**Command:** Toggle Line Comment

* **Windows/Linux:** `Ctrl + /`
* **Mac:** `Cmd + /`

**Use Case:** Comment or uncomment multiple CSS lines quickly during testing.

---

## Summary

These shortcuts make CSS editing in VS Code much faster and more efficient. Learning to combine them (for example, using multi-cursors and then joining lines) can significantly improve your coding workflow.
