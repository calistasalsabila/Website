# Landing Page Case Study: Coding Course

This document explains a **landing page structure** for a *Coding Course* website. The goal of this landing page is to clearly communicate value, build trust, and drive users toward a **Call To Action (CTA)** such as enrolling in a course.

---

## Overview

A landing page is a **single-purpose web page** designed to guide users toward a specific action. In this case, the action is related to joining or learning more about a coding course.

This case study focuses on a **simple but effective structure**:

1. Header + Hero Section
2. "Why" Section + Advantages Section
3. Call To Action (CTA) + Footer

---

## 1. Header + Hero Section

### Header

The header is the first navigational element users see.

**Purpose:**

* Provide branding
* Offer quick navigation
* Establish credibility

**Common Elements:**

* Logo / Brand name
* Navigation links (Home, Course, Pricing, Contact)
* Login / Sign Up button (optional)

**Best Practices:**

* Keep it minimal
* Make it sticky if needed
* Ensure clear contrast with background

---

### Hero Section

The hero section is the **most important section** of the landing page.

**Purpose:**

* Instantly explain what the product is
* Capture attention
* Encourage users to scroll or take action

**Key Elements:**

* Main headline (value proposition)
* Supporting subheadline
* Primary CTA button
* Visual element (illustration, image, or video)

**Example Content:**

* Headline: *Learn Coding from Scratch*
* Subheadline: *Build real-world projects with guided mentorship*
* CTA: *Start Learning Now*

**Best Practices:**

* Use concise and clear language
* Focus on benefits, not features
* Make CTA visually dominant

---

## 2. Why Section (Kenapa Section)

This section answers the question:

> **Why should users choose this coding course?**

**Purpose:**

* Address user doubts
* Explain the problem being solved
* Build relevance

**Common Content:**

* Pain points of beginners
* Problems with traditional learning methods
* Challenges learners usually face

**Example Topics:**

* Confusing learning paths
* Lack of real projects
* No mentorship or feedback

**Best Practices:**

* Speak from the user’s perspective
* Use simple language
* Keep it empathetic and relatable

---

## 3. Advantages Section (Keunggulan Section)

This section highlights the **unique strengths** of the coding course.

**Purpose:**

* Differentiate from competitors
* Reinforce trust
* Highlight value

**Typical Advantages:**

* Structured curriculum
* Real-world projects
* Mentorship or community support
* Lifetime access to materials

**Layout Ideas:**

* Grid of feature cards
* Icons with short descriptions
* Side-by-side comparison

**Best Practices:**

* Focus on outcomes
* Keep descriptions short
* Use visual hierarchy clearly

---

## 4. Call To Action (CTA) Section

The CTA section is where conversion happens.

**Purpose:**

* Push users to take action
* Reduce hesitation

**Common CTA Actions:**

* Enroll now
* Join the course
* Start learning today

**Key Elements:**

* Strong CTA headline
* Short supporting text
* Action-oriented button

**Best Practices:**

* Use action verbs
* Create urgency if relevant
* Make the CTA button highly visible

---

## 5. Footer

The footer is the closing section of the page.

**Purpose:**

* Provide additional information
* Offer secondary navigation
* Establish professionalism

**Common Elements:**

* Copyright notice
* Social media links
* Contact information
* Terms & Privacy links

**Best Practices:**

* Keep it clean
* Avoid overwhelming content
* Maintain visual consistency

---

## Summary

This landing page structure ensures:

* Clear messaging
* Logical content flow
* Strong conversion focus

By combining a compelling hero section, persuasive explanation, clear advantages, and a strong CTA, the coding course landing page becomes effective and user-focused.
